深色主题**单一**(主播暗光环境),不做浅色。

### 字体 / 字号

- 字体族:**Noto Sans SC**(思源黑体)回退系统无衬线。App 内打包或用系统思源。
- 字号(sp):页面大标题 22/700;歌名 20/700(演唱顶部)、17/700(卡片);逐字歌词**大字 30/700**、下一行 17;列表歌名 16/500;歌手/说明 13;胶囊/次要 12;极小标签 10–11。数字用 `tabular-nums`(等宽,进度/时间/音量不跳)。

### 圆角 / 间距 / 触控

- 圆角:卡片/输入 **14–16**;胶囊/小按钮 9–13;圆形按钮全圆。
- 主圆按钮 60dp(播放)、场景大按钮高 56、遥控 BGM 主键 58、次圆钮 46–48、迷你场景高 34。
- **触控目标 ≥48dp**。页边距 16。卡片间距 10。
- 发光:主按钮 `shadow 0 6px 22px accentGlow`;选中场景 `0 5px 18px accentGlow`。

### 动画

| 名 | 用途 | 参数 |
|---|---|---|
| `spin` | 加载转圈、断连横幅小圈 | 0.8s linear 无限 |
| `reglow` | 「演唱中」橙点呼吸 | 1.4s ease-in-out,opacity .55↔1 |
| `fabpulse` | 悬浮球播放时脉冲光环 | 2s ease-in-out |
| `sheetup` | 点歌抽屉上滑 | 0.24s ease,translateY 100%→0 |
| 逐字上色 | 歌词字 idle→青 | color transition .09s |

## 三、逐屏规范

### 3.1 演唱页(屏1)

竖屏从上到下五段:

1. **顶部信息条**(padding 14/16):左歌名 20/700(超长省略)+ 歌手 13/dim;右侧一排:连接状态点(11dp,可点进设置)、调号胶囊(青字 `原调`/`+2`/`-1`,**纯标签**)、**音源切换按钮**(`伴奏`/`原唱` + `⇄`,青底 14% + 青边 55%,**可点切换原唱/伴奏**,样式区别于左侧纯标签胶囊)。下方进度条(高 4,青已播/`#23262F` 未播)+ 左青时间/右灰时间。
2. **音准线区**(高 **172dp** 固定,渐变 `#101219→#0C0D12`,上下描边 `#191C24`):
   - 播放头竖线在宽度 **30%** 处(`HEAD_RATIO`,青色),顶部一个青圆点。
   - 背景两条水平参考线(top 33%/66%,`rgba(255,255,255,.04)`)。
   - 音符块从右往左滚:**几何全用 dp**(`DrawScope` 内 `.dp.toPx()`,否则高 DPI 手机上又小又挤成散点):高 `NOTE_H_DP=10`、横向 `DP_PER_SEC=60`(每秒 60dp,约一屏 5~6 秒,时间密度贴近 PC);纵向 = 归一化音高压进 `[0.12,0.88]`(留上下白边,仿 PC ±2 半音);x = `headX + (start - t)*60dp/s`。**唱到**(t 在 [start,start+dur))→ 底色青 + 白色进度填充(宽 = 唱过比例);否则底色 `#3D6FC9`。
   - 前奏/间奏(无音符经过头):底部居中 `♪ 歌名 - 歌手`(13/`#6B7180`)。
3. **歌词区**(flex 居中,gap 16):
   - 前奏态:上方一排 **4 个 KTV 引导圆点**(11dp,青带光/灭 `#2A2E39`),随倒计时逐个熄灭(`lit=ceil((b-t)/step)`,step=段时长/4);**提前全亮、最后几秒才递减**。
   - 当前行:大字 30/700 居中,**逐字**从左到右 idle 白 `#EEF1F6`→已唱青 `#45D6FF`(+青光 text-shadow),transition .09s。
   - 下一行:17/`#8A90A0` 居中。
4. **控制条**(顶描边 `#191C24`,底 `#0D0E13`):
   - **声卡场景快切行**:`声卡` 小标签 + 5 个迷你按钮(聊天/湿唱/干唱/喇叭/闭麦,高 34,选中青底近黑字/未选 `#1A1D25`+`#9AA0B0`),**无归位**,与遥控页场景同步。
   - 中间一行小字:`下一首:歌名 · 歌手`(队列预览;空则 `下一首:队列已空`)。
   - 主控行:降/升调胶囊(`−` `原调` `+`,调号青字带 `AnimatedContent` 过渡,clip [-6,6])、**步退**圆钮(48,双三角)、**播放/暂停**主圆按钮(60,青底)、**步进**圆钮(48)。**音源(原唱/伴奏)切换已移到顶部信息条**,主控行不再放,腾出空间;**演唱页不放切歌**——切歌在队列页。
5. **空状态**(无当前歌):话筒圈图标 + `还没开始唱` 26/700 + 副文案 + 青按钮 `去点歌 →`(跳队列并弹抽屉)。
6. **加载遮罩**(切歌):`inset:0` 半透黑 + 模糊 + 转圈 + `歌曲加载中…`。

### 3.2 队列页(屏2)

- 顶部标题 `队列` 22/700 + 连接点;右侧 `清空队列`(dim,可点)。
- **「演唱中」卡片**(青描边 1.5、青渐变底):橙点(呼吸)+ `演唱中` 11/700/橙 + 歌名 17/700 + 歌手 + 细进度条;右侧 ⏭ 圆钮(46,青)= `kqueue_next` 切下一首。无当前歌则不显示。
- **点歌按钮**:青虚线框(`1.5px dashed`)+ 青底 6% + `＋ 点歌 · 从曲库加歌` → 打开抽屉。
- **等待队列**:标题行 `等待队列 · N` + 右 `长按 ≡ 拖动重排`。每行卡片:拖动手柄(⠿,`cursor:grab`)、序号、歌名 16/500 + 歌手、置顶钮(↑,→ `kqueue_next` 效果=移到队首/下一首)、删除钮(×)。**长按(~180ms)拖动重排**:被拖行抬起(阴影+青边+`#232733`),原位留**青色虚线占位空槽**;拖动步进 = ROW 高(72)。
- 空状态:`队列空了` + 副文案。

### 3.3 遥控页(屏3)

- 标题 `遥控` + 右上连接胶囊(点/`已连 IP`|`未连接`)。
- **声卡场景**:小标题 + 3列网格 5 个大按钮(56 高,选中青)+ 下方 `归位（长按确认）`。
- **背景音乐 · QQ音乐** 卡片:居中三键(上一首 46 / 播放暂停 58 青 / 下一首 46)+ 音量滑条(0–100,`accent-color` 青)+ 数值 + 只读 `{bgmNow}`(歌名 + 进度)。
- **窗口开关** 卡片:两行 Switch —— `Studio One 显示/隐藏`、`K歌歌词 显示/隐藏`。轨道开青/关 `#2A2E39`,滑块白 24dp 位移 20。

### 3.4 点歌抽屉(底部弹层,全局)

- 蒙层 `rgba(0,0,0,.55)` 点击关;面板 `#101219` 顶圆角 22,最高 84%,`sheetup` 动画,顶部 40×4 抓手。
- 标题 `点歌` + 关闭圆钮;搜索框(`搜歌名或歌手…` + 放大镜)。
- 分组 `最近入库`(+`备货` 青标签)/ `全部`;每行:歌名 16/500 + 歌手(可带 `· 副标题`)+ 时长 + 右青圆 `+` 钮。**加歌后不关抽屉**(可连点),`+`→短暂变绿 ✓ + toast `已加入队列`(1.2s 复位)。

### 3.5 悬浮 QQ音乐迷你控制台(全局,除遥控页)

- **常驻悬浮球**(52dp,毛玻璃 `rgba(18,20,27,.72)`+blur、青描边):音乐图标 + 右下状态点(绿=播放/`#6B7180`=暂停);播放时 `fabpulse` 光环。
- **可拖动**任意位置(位移>5px 视为拖动、不触发展开);首页初始停在声卡控制条上方(right16/bottom236 附近),不遮按钮。
- **点击展开**半透明毛玻璃面板(260 宽,右14/底78):标题 `QQ音乐 · 背景音乐` + 关闭 + `{bgmNow}` + 三键 + 音量条。**点面板外(失焦)收起**。
- 遥控页不显示(那有完整 BGM 卡片)。

### 3.6 连接 / 设置

- 全局顶部状态点绿(已连)/红(断开);断开时页顶细横幅 `与电脑断开,重连中…`(带 spin 小圈)。
- 设置页(覆盖层):返回 + `连接电脑`;状态点 + `已连 IP`/`未连接`;`电脑局域网 IP` 输入 + `连接` 青按钮;`已记住上次连接的电脑`。

## 四、状态 → 后端字段映射(与 pc-service ②-2 WS/HTTP 对齐)

见 [live-remote/README.md](../live-remote/README.md#k歌-api手机点歌控制--阶段-2已接入)。要点:

| UI | 数据来源 | 指令 |
|---|---|---|
| 演唱顶部歌名/歌手/进度/调/音源 | WS `now`/`k_pos`/`k_dur`/`k_key`/`k_vocal` | 升降调 `kkey`{semi};音源 `kvocal`{on};步进步退 `kseek`{ms};播停 `kplaypause` |
| 伴奏音量(手机物理音量键) | WS `k_vol`(0-100) | 音量键调手机媒体音量后发 `kvol`{value=百分比};开唱换歌时同步一次 |
| 逐字歌词 + 音准线 | **待后端补**(QRC 逐字时间轴 + `.note` 音高;②-2 未含) | 只读,靠 `k_pos` 本地插值 |
| 声卡场景(两处) | 本地 `scene`(WS 暂无回读) | `{"cmd":"scene","id":N}` |
| 队列 / 演唱中卡片 | WS `queue` / `now` | `kqueue_add/remove/next/clear` |
| 点歌抽屉曲库 | `GET /library` | `kqueue_add`{mid} |
| QQ音乐 悬浮/遥控 | WS `bgm_vol` 等(沿用现有) | `bgm`{action}、`bgm_vol`{value} |
| 窗口开关 | WS `player_visible` 等 | `player_toggle`/`kshow`/`khide`、`studio_toggle` |

**演唱↔BGM 联动(纯前端)**:检测「有当前歌且播放中」跳变——开唱→发 `bgm` 暂停 + toast;停唱/空队列/暂停→恢复 + toast;悬浮球状态点随之变。
