# 直播K歌手机端 · UI 设计文案(给设计工具出原型用)

> 用法:把本文整篇(或按屏分段)贴进 Claude design / 设计工具,生成高保真原型。产出后我再据原型定
> 组件规范并用原生 Kotlin 开发。**手机竖屏(Portrait)**,深色主题。

---

## 一、产品是什么 / 谁在用

一个**直播唱歌的主播**用的手机 App。主播一边直播一边唱歌,人经常离开电脑。这台手机 App 通过局域网
连电脑(pc-service 中枢),是主播的**歌房遥控台**:点歌、管理队列、看卡拉OK字幕和音准线、切声卡场景、控背景音乐。

- 电脑负责:出伴奏、渲染绿幕歌词给**直播观众**看。
- 这台手机负责:给**主播本人**看卡拉OK字幕+音准线、点歌排队、遥控。
- 体验目标:像**全民K歌的"歌房"**——既能点歌管队列,又能看着字幕和音准线唱。

## 二、设计风格

- **深色 KTV 质感**:近黑背景(#0E0F13 ~ #16181F),卡片深灰(#1C1F27)。主播常在暗光环境,深色护眼、显字幕。
- **主强调色:电光青 #45D6FF**(和字幕高亮一致),用于当前项、进度、音准高亮、主按钮。
- 次强调:暖橙 #FF9F45(用于"正在唱/直播中"这类状态点)。
- 文字:主文字近白 #F2F4F8,次要文字灰 #8A90A0。
- 字体:无衬线,中文思源黑体/系统默认;字号偏大(主播是"瞥一眼"操作,不是细看)。
- 触控目标大(≥48dp),圆角 12–16dp,适度发光/渐变营造舞台感,但别花哨到干扰读字幕。
- 顶部常驻一个**连接状态点**:绿=已连电脑,红=断开(点它进设置改电脑IP)。

## 三、导航结构

底部 **TabBar 四个页签**(图标+文字):

1. 🎤 **演唱**(默认主页) 2. 🔍 **点歌** 3. 📋 **队列** 4. 🎛 **遥控**

## 四、逐屏设计

### 屏 1 · 演唱(歌房主页,默认)

主播唱歌时盯着这屏。竖屏从上到下:

1. **顶部信息条**(约 12% 高)
   - 左:当前歌名 + 歌手,例:**吉姆餐厅** · 赵雷
   - 右:两个小胶囊标签:调号(如 `原调` / `+2` / `-1`)、音源(`伴奏` / `原唱`)
   - 下方一条细进度条 + 时间 `1:12 / 5:53`(青色已播,灰色未播)

2. **音准线区**(约 28% 高)——横向滚动的"音高提示条"
   - 一条竖直播放头线在左侧约 28% 处;音符块从右往左滚动经过它。
   - 音符块=蓝色圆角条(带黑描边),纵向位置=音高高低;正在唱到的那块高亮青色 #45D6FF、带白色进度填充。
   - 这是卡拉OK的"音准线",给主播对音高。前奏/长间奏时这里空。

3. **歌词区**(约 40% 高)——卡拉OK逐字字幕
   - **当前行**大字居中(约 30sp 加粗),**逐字从左到右扫过高亮成青色**(已唱=青,未唱=白/浅灰)。
   - **下一行**小一号、灰一点,居中在当前行下方(两行靠近)。
   - **前奏/长间奏**:提前把该行歌词显示出来(等着),行上方一排"KTV 引导圆点"(4个),随倒计时逐个熄灭,
     归零瞬间无缝接上逐字高亮。前奏还显示 `♪ 吉姆餐厅 - 赵雷`。
   - 示例当前行:`不灭的月亮下是不夜的街`(前半青、后半白),下一行:`生意不错 忙碌的人把一切忘了`

4. **控制条**(底部、TabBar 之上,约 14% 高)——大按钮,一排:
   - `降调 −`(左)/ 中间显示当前调号 / `升调 +`(右)
   - `原唱 / 伴奏` 切换(图钉/切换态)
   - `⏯ 播放/暂停`(主按钮,青色圆形,最大)
   - `⏭ 下一首`(切到队列下一首)
   - 控制条上方一行小字:`下一首:郭源潮 · 宋冬野`(队列预览)

**空状态**(当前没在唱):中间大字 `还没开始唱`,副文案 `去"点歌"选一首,或在电脑K歌里唱一首备货`,一个
青色按钮 `去点歌 →`。

### 屏 2 · 点歌

1. 顶部**搜索框**:占位文字 `搜歌名或歌手…`,右侧放大镜。
2. 下方**曲库列表**(可滚动),每行(卡片):
   - 左:歌名(主文字)+ 歌手(次文字),例:`野心家` / `张靓颖`
   - 右:一个青色圆形 `+` 按钮 = 点歌加入队列(点后短暂变 ✓ + 顶部 toast `已加入队列`)
   - 可选小字:时长 `5:53`
3. 列表可分组:`最近入库`(置顶,给刚唱过备货的歌)/ `全部`;新歌入库**实时出现**(顶部轻提示 `曲库+1`)。
4. 示例数据:吉姆餐厅·赵雷 / 不开的唇·赵雷 / 郭源潮·宋冬野 / 野心家(《灼灼韶华》主题曲)·张靓颖。

**空状态**:`曲库还没有歌`,副文案 `先在电脑上用全民K歌唱一首,会自动收进曲库`。

### 屏 3 · 队列

1. 顶部**"正在唱"卡片**(青色描边高亮):歌名歌手 + 一个小进度条 + 状态点 `● 演唱中`;右侧一个 `⏭` 快捷切下一首。
2. 下方**"等待队列"列表**,每行:
   - 序号/拖动手柄(≡,可**长按拖动重排**)
   - 歌名 + 歌手
   - 右侧两个操作:`置顶/下一首`(↑)、`删除`(×)
3. 顶部或底部一个次要按钮 `清空队列`。

**空状态**:`队列空了`,副文案 `去点歌把想唱的排上`,按钮 `去点歌 →`。

### 屏 4 · 遥控(沿用现有电脑遥控能力,做成原生)

1. **声卡场景**:一排/网格 5 个大按钮:`聊天` `湿唱` `干唱` `喇叭` `闭麦`,当前场景高亮青色。下面一个
   次要按钮 `归位`(长按确认)。
2. **背景音乐(QQ音乐)**:一行三键 `⏮ 上一首` `⏯ 播放/暂停` `⏭ 下一首` + 一条**音量滑条**(0–100,带数值)。
   下方只读小字:当前 BGM 歌名 + 进度(如 `蒙面哥 - 从来没有忘记过 0:43/4:27`)。
3. **窗口开关**:两个开关行 `Studio One 显示/隐藏`、`K歌歌词 显示/隐藏`(带勾选态)。
4. 顶部显示连接地址与状态(`已连 192.168.1.x` 绿点)。

## 五、跨屏与状态

- **连接状态**:全局顶部小圆点(绿/红)。断开时演唱/点歌等页顶部出现一条细横幅 `与电脑断开,重连中…`。
- **首次启动/设置**:一个简单页,输入电脑局域网 IP(如 `192.168.1.6`),`连接` 按钮;记住上次。
- **进度同步**:演唱页的字幕/音准/进度由电脑推送驱动(主播这屏和直播观众看到的完全同步)。
- 需要设计的状态:已连/断开、未在唱/演唱中、曲库空、队列空、歌曲加载中(转圈)。

## 六、给设计工具的产出要求

- 出**4 个主屏 + 空状态 + 设置页**的高保真竖屏原型,深色主题,青色强调。
- 演唱页是重点:音准线区 + 逐字高亮歌词 + 底部控制条,要能一眼看懂"这是卡拉OK歌房主页"。
- 组件尽量复用统一(卡片、胶囊标签、圆形主按钮、列表行 + 操作按钮、底部 TabBar)。
