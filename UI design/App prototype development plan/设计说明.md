## 二、逐屏说明

### 屏 1 · 演唱(主页)
- **顶部信息条**:歌名 + 歌手、调号胶囊、音源胶囊、连接状态点(点击进设置);下方进度条 + 时间。
- **音准线区**:蓝色圆角音符块从右往左滚过左侧 28% 的青色播放头,经过时高亮青并带白色进度填充;前奏/间奏空档显示 `♪ 歌名 - 歌手`。
- **歌词区**:当前行大字居中、逐字从左到右扫描高亮成青;下一行小一号灰字;前奏时上方 4 个 KTV 引导圆点随倒计时逐个熄灭。
- **控制条**:声卡场景快切行 + 下一首预览 +（升降调 / 步退 / 播放暂停 / 步进 / 音源)。
- **空状态**:`还没开始唱` + 去点歌按钮。加载切歌时中央转圈。

### 屏 2 · 队列(含点歌入口)
- 顶部「演唱中」青色描边卡片(橙色状态点 + 进度 + 切下一首 ⏭)。
- 「＋ 点歌 · 从曲库加歌」按钮 → 底部弹出选歌抽屉。
- 「等待队列」列表:拖动手柄 ≡、序号、歌名歌手、置顶(↑)、删除(×);**长按拖动重排**。
- 顶部「清空队列」;空状态 `队列空了`。

### 屏 3 · 遥控
- **声卡场景**:5 个大按钮(聊天/湿唱/干唱/喇叭/闭麦)+ 归位。
- **背景音乐 · QQ音乐**:上一首/播放暂停/下一首 + 音量滑条 + 只读当前 BGM。
- **窗口开关**:Studio One、K歌歌词 显示/隐藏。
- 顶部连接地址与状态。

### 点歌抽屉(底部弹层)
搜索框 + `最近入库`(备货)+ `全部`,青色 `+` 加入队列(变 ✓ + toast),加歌后不关闭可连续点。

### 设置页
局域网 IP 输入 + 连接;「断开演示」开关触发断开态与顶部重连横幅。

## 三、跨屏与状态
- **连接**:全局状态点(绿/红),断开时顶部细横幅 `与电脑断开,重连中…`。
- 覆盖状态:已连/断开、未在唱/演唱中、曲库/队列空、切歌加载中(转圈)。
- 数据流打通:点歌 → 进队列 → 演唱(切歌自动出队、可到队尾进入空状态)。
- 右上角 Tweaks 可调:起始页 / 连接 / 自动播放。

## 四、原始需求之外的补充改动

> 以下为在原始《UI_DESIGN.md》基础上,经沟通新增/调整的内容,便于后续 Kotlin 开发时区分。

### 1. 导航结构调整:四页签 → 三页签
- 原设计为「演唱 / 点歌 / 队列 / 遥控」四个页签。
- **改动**:取消独立「点歌」页,与「队列」页合并;点歌改为队列页内的一个按钮,点击从底部弹出选歌抽屉。TabBar 变为三页签。

### 2. 演唱页控制条:切歌 → 步进/步退
- **改动**:演唱页控制条移除「下一首」,改为 **步退 / 步进**(±5s 定位)。
- **切歌只在队列页执行**(「演唱中」卡片右侧 ⏭)。

### 3. 演唱页新增声卡场景快切行
- **改动**:演唱页控制条上方新增一行 5 个小按钮(聊天/湿唱/干唱/喇叭/闭麦,**不含归位**),与遥控页场景状态同步,唱歌时无需切页即可换场景。

### 4. 悬浮 QQ音乐迷你控制台
- **改动**:除遥控页外,常驻一个半透明悬浮球控制 QQ 音乐。
  - 平时收起为小圆钮(带播放状态小圆点,绿=播放/灰=暂停)。
  - 点击展开为半透明毛玻璃小面板(上一首/播放暂停/下一首 + 音量)。
  - **可拖动**到任意位置(拖动不误触展开);首页初始停在声卡控制条正上方,不遮挡按钮。
  - 展开后点击面板外区域(失焦)自动收起。

### 5. 队列长按拖动 + 占位空槽
- **改动**:等待队列支持长按手柄拖动重排;拖动时原位留下**青色虚线占位空槽**,被拖行悬浮抬起,其它行让位。

### 6. 演唱 ↔ 背景音乐 联动
- **改动**:开始演唱(有歌且播放中)**自动暂停** QQ 音乐;停止演唱 / 切到空队列 / 暂停时**自动恢复**播放,并有轻提示。悬浮球状态点随之变化。

### 7. TabBar 图标
- **改动**:补充并内联三个页签 SVG 图标(话筒 / 播放列表 / 遥控器),提亮未选中色、加深底栏以保证对比度。
